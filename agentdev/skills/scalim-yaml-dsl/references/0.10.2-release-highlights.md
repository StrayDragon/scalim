# 0.10.2 版本亮点（agent）

## 何时读取

- 用户从 **0.10.1** 升到 **0.10.2**，问「YAML 要不要改 / lookup_chunk_size / 要不要开观测」
- 人类文档总览：`docs/doc/releases/0.10.2/index.md`
- typed `Event`（0.10.1）仍见：`0.10.1-release-highlights.md`
- 0.10.0 性能三项仍见：`0.10-release-highlights.md` + `docs/doc/releases/0.10.0/`

## 硬结论（先说）

- **YAML Breaking**：`sources.*.lookup_chunk_size` 已迁出；继续写会 **fail-fast**。改 `DemandRunRuntimeOptions.lookup_chunking` + `LookupChunking`。
- **观测为 opt-in**：生产 / 正式非 DEBUG 可保持 `components=[]`；开发服 / bench 再用 `ObservabilityProfile`。
- typed Observer/Hook 仍收完整 `Event`（0.10.1 契约不变）。
- 0.10.0 的 write-precompute / fusion / chunk 并行默认与开关**不变**（并行挂在 `LookupChunking.sized(..., parallel=True)` 时见 upgrade 卡）。
