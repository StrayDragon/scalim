# 0.10.1 版本亮点（agent）

## 何时读取

- 用户从 **0.10.0** 升到 **0.10.1**，问「要不要改 YAML / Observer Hook 会不会挂」
- 人类文档总览：`docs/doc/releases/0.10.1/index.md`
- 0.10.0 性能三项仍见：`0.10-release-highlights.md` + `docs/doc/releases/0.10.0/`

## 硬结论（先说）

- **YAML authoring 主线无强制迁移**。
- **Python Breaking**：typed Observer/Hook `on_*` 入参为完整 `Event`（不是 payload dataclass）。
- 无双签名兼容层：经 `event.payload` / `event.meta` 迁移。
- 0.10.0 的 write-precompute / fusion / chunk 并行默认与开关**不变**。

## 适配注意

### typed handlers → `Event`

- 检索：`def on_field_compute` / `on_loader_call` / `EventDispatchObserver` / `BaseHook`，以及 `event.field_key` 等直读 payload 字段。
- Before/After：`scalim-public-api/references/upgrades/2026-08-02-typed-handlers-receive-event.md`
- 任务卡：`scalim-public-api/references/task-event-type-adaptation.md`

### phase meta

- `FIELD_COMPUTE` 的 `meta.scalim_compute_phase` 在 typed 路径可读；不必仅为 phase 覆写 `on_event`。
