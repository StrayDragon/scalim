写出布局：建议而不自动改

Change c40-output-write-layout-advisory 研究页（由 Cursor canvas 转静态 HTML）。 证据：scripts/bench_output_write_layout_dual_run.py --preset medium（2026-08-11）。

一句话：宽表 Excel 用 WINDOW 往往更省内存；默认不能偷偷改写出方式。 系统只「告诉你」，你再显式设 OutputWriteLayout.COLUMN_WINDOW。

1. 三种装车方式

row_stream 一行一行写

YAML books / 多表组合只能走这条。不是列式 WINDOW 的优化对象。

column_hold 整列先攒齐

默认列式 Excel：每列整表先在内存，宽表峰值高。

column_window 按窗刷列

列式 Excel 按行窗推进；峰值通常更低，墙钟往往差不多。

2. 为什么这样做

  • 问题：宽表 + HOLD 顶内存；WINDOW 更省，但改路径影响峰值时机与可复现性。
  • 错误做法：运行时静默 HOLD↔WINDOW。
  • 梯子：L0 显式 Enum（c30 已落地）→ L1 建议（本 change）→ L2 opt-in auto（另案）→ L3 默认 auto（不做）。
原则：信息够做「建议」，不够做「默认自动」。错切比少建议更贵。

3. 若改成 WINDOW，正确性有问题吗？

短答：在合法 IR 列式路径下，业务格子（行×列取值）与 HOLD 等价；不是 xlsx 文件字节相等。非法组合会 fail-fast，不会静默写出假开关结果。
维度结论说明
业务格子 / 行数 应等价 测试：HOLD vs WINDOW 矩阵对拍；双跑断言 rows_equal。
xlsx 字节 不必相等 write_only / 压缩 / 元数据不同；对拍用业务列，勿比文件 hash。
YAML books / composition 不能靠 WINDOW「修」 组合层强制行流；与 WINDOW 同开 → fail-fast。要 WINDOW 须迁 IR 列式。
行式 streaming=True 非法 WINDOW 仅列式 excel + 非 streaming；否则 fail-fast。
调用契约差异 更严 WINDOW：每窗 set_row_ids 后须写满列；未齐备 → close 报错（防半截表）。
一次 set 全量行 仍「正确」但省内存差 会预分配大壳；峰值收益差——应 batch 追加 set_row_ids。
公式 / 样式等高级 Excel 非本开关承诺 列式 sink 路径以单元格值为准；勿假设与某 GUI 模板字节级一致。

因此：advisory 在 safe=true 时推荐的「显式改 WINDOW」是性能旋钮，不是正确性赌博； safe=false（如 composition）只提示迁路径，禁止写「设 WINDOW 就好」。

4. 代码例子

默认（不设）

# 不设 output_write_layout
# excel + streaming=False + HOLD
# → effective = column_hold

显式 WINDOW

from scalim.dsl.yaml_dsl import (
    DemandRunOptions,
    DemandRunRuntimeOptions,
    OutputWriteLayout,
    run,
)

run(
    "demand.yaml",
    options=DemandRunOptions(
        runtime=DemandRunRuntimeOptions(
            output_write_layout=
              OutputWriteLayout.COLUMN_WINDOW,
        ),
    ),
)

6. L1 生效后你会看到什么（假想）

current column_hold → suggested column_window   safe=true   wide_excel_peak_risk 

{
  "suggested": "column_window",
  "current_effective": "column_hold",
  "reason_code": "wide_excel_peak_risk",
  "reason_detail": "n_fields*n_rows exceeds threshold",
  "action": "set DemandRunRuntimeOptions(output_write_layout=OutputWriteLayout.COLUMN_WINDOW)",
  "safe": true
}

这次写出不变；下次你复制 action 显式改 options 才变。
