# Benchmark 对比报告

!!! warning "历史存档（请勿引用）"
    本页是 scalim **0.9 之前**开发期的内部对拍实验存档：无版本号、无测量环境、无日期、无复现脚本，
    版本代号（`legacy_seq` / `splitloaders_*`）为当时内部命名。**本页数字不具备对外引用条件。**

    当前对外引用请使用版本锚定的 [外部基线对比](external-baseline.md)（含复现脚本与数据 JSON）。

??? note "适用读者"
    - 关注对比结论与差异项的开发者/数据同学
    - 需要回溯输出文件/日志路径的项目贡献者
